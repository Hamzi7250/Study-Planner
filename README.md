# My AI Study Planner

## About the Project

My AI Study Planner is a beginner-friendly Python project that helps students organize their AI learning schedule.

The program collects student information, calculates total weekly study hours, displays a personalized study plan, and saves the plan in a text file.

## Features

- Collects the student's name
- Accepts an AI learning goal
- Sets study days per week
- Sets daily study hours
- Calculates total weekly study hours
- Displays a personalized study plan
- Saves the plan to `study_plan.txt`
- Handles invalid input

## Requirements

- Python 3
- No external packages required

## How to Run

1. Open a terminal in the project folder.
2. Run:

   ```bash
   python main.py
   ```

3. Enter the requested information.
4. Find your saved plan in `study_plan.txt`.

## Example Calculation

If a student studies 2 hours per day for 5 days:

Weekly Study Hours = 2 x 5 = 10 hours
